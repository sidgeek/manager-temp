01先想清楚：你想获得什么？

明确你的目标，才能挑出合适的请求书

RFI 问能力 · RFQ 问价格 · RFP 要方案。核心区别在于：你要的是信息、价格，还是完整解决方案。

RFI
Request for Information
信息请求书
了解市场与供应商能力

适合需求尚未清晰、希望收集市场信息、希望供应商展示能力与经验的早期探索阶段。

你可以问：
  • 你们能提供什么？
  • 你们有哪些经验和能力？
  • 市场上有哪些可行的选择？
RFQ
Request for Quotation
报价请求书
获得明确规格下的价格

适合采购内容已经清楚、有明确的技术规格、数量和要求，重点在于比较供应商的报价。

你可以问：
  • 在这些明确的规格下，你们的报价是多少？
  • 还有哪些费用需要考虑？
RFP
Request for Proposal
建议书邀请书
获得解决方案与实施建议

适合需要综合考虑技术与商务方案，希望供应商提供完整的解决方案、实施计划和相关建议。

你可以问：
  • 你们如何理解我们的需求？
  • 你们的解决方案是什么？如何实施？
  • 有哪些优势和创新？

02供应商评审规则

按事先公布的选择因素评审，确保公平、公正、透明。

技术符合性报价交付周期
是否满足技术需求和业务需求在满足要求的前提下进行价格比较能否接受要求的时间完成交付
重要提醒

不能在评审过程中临时增加"赠送大屏"作为评审因素。
评审应严格依据事先公布的选择因素进行，不能在评审过程中随意增加新的评审因素。

RFI 问能力（信息），RFQ 问价格（报价），RFP 要方案（建议书）。
要清楚的问题，来自清楚的目标。
