01质量成本两大类

一致性成本

为了把事情做好而花的钱

  • 预防成本：防止缺陷发生，提前投入的成本
  • 评估成本：检查有没有缺陷，进行评估的成本
非一致性成本

事情没做好以后付出的代价

  • 内部失败成本：在交付前发现问题而产生的成本
  • 外部失败成本：在交付后发现问题而产生的成本

02四类质量成本典型举例

预防成本
关键词：防止缺陷发生
  • 培训
  • 规范制定
  • 流程建设
评估成本
关键词：检查有没有缺陷
  • 测试
  • 检查
  • 质量审计
内部失败成本
关键词：交付前发现问题
  • 返工
  • 报废
  • 重新测试
外部失败成本
关键词：交付后发现问题
  • 客户投诉
  • 整改 / 赔偿
  • 售后修复

03今日案例题

案例背景：为赶进度取消代码评审 → 测试阶段大量返工 → 交付后客户发现严重问题

评分点分析：
  1. 未进行代码评审 → 质量管理不到位
  2. 过度依赖最终测试 → 忽视过程质量管理
  3. 测试阶段大量返工 → 内部失败成本
  4. 客户交付后发现问题 → 外部失败成本
  5. 材料没有说的，不要自己脑补

04案例题答题方法

找事实 → 做判断 → 对应过程 → 写标准术语
一个问题 = 一个评分点
❌ 错误示范：预防、评估成本过低导致外部失败
✅ 正确做法：只写材料能够证明的内容 | 不把多个问题强行合并
