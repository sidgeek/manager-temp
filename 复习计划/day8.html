同样一句"月底完成上线准备"，不同角色的理解可能完全不同

02项目沟通管理三大过程

01

规划沟通管理

定规则Plan Communications Management

明确沟通对象、内容、责任人、频率与渠道。

02

管理沟通

传信息Manage Communications

生成、收集、发布、存储和传递项目信息。

03

监督沟通

查效果Monitor Communications

检查沟通是否满足干系人的信息需求，必要时调整。

沟通闭环：规划 → 执行 → 检查 → 改进，形成闭环

→
调整沟通安排（持续改进）

03沟通的基本机制

信息在发送者和接收者之间传递，并通过反馈实现理解一致
发送者（想法清晰）
→
编码（形成语言）
→
信息与沟通渠道（语言、文字、会话等）
→
接收者解码（理解信息）
→
反馈确认（是否理解）

常见陷阱：信息不明确（发送者）· 渠道不合适（渠道）· 理解不一致（解码）· 缺少反馈（确认）。

发送成功，不代表对方已经理解。

收集需求 → 定义范围 → 创建工作分解结构 → 确认范围 → 控制范围
风险管理风险定性分析；制定风险应对；持续监督
实施定性风险分析；规划风险应对；监督风险
整合管理遗漏制定项目管理计划；遗漏监控项目工作
制定项目章程 → 制定项目管理计划 → 指导与管理项目工作 → 监控项目工作 → 实施整体变更控制
资源管理遗漏规划资源管理；估算资源（名称改写）
规划资源管理 → 估算活动资源 → 获取资源 → 建设团队 → 控制资源
