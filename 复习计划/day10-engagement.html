01参与度五级阶梯

先看当前状态，再决定希望他达到什么状态

从"不了解"到"领导"，参与程度逐级上升，管理策略也逐级加强。

不了解

不了解项目存在及其影响

→
抵制

知道项目，但反对项目工作或变化

→
中立

知道项目，既不支持也不反对

→
支持

了解项目，并支持项目工作与成果

→
领导

积极参与，并主动推动项目成功

不了解 ≠ 中立 支持 ≠ 领导

02干系人参与评估矩阵

Stakeholder Engagement Assessment Matrix
C = Current = 当前参与水平　·　D = Desired = 期望参与水平
干系人不了解抵制中立支持领导
一线客服人员 C D
读法：一线客服人员当前抵制，期望支持。

03从抵制到支持：不是直接改表，而是先解决问题

了解顾虑
→
邀请测试
→
收集反馈
→
开展培训
→
持续检查参与情况

根据实际变化，再更新矩阵记录。

重要提醒

C 和 D 记录的是事实与目标，不是主观愿望。
不能因为希望对方支持，就直接把当前状态写成支持。

参与度管理：先如实评估现状，再设定合理目标，用行动缩短差距。
