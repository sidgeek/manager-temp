01成本管理四大过程：EVM 用在哪一步？

01

规划成本管理

定规则

确定如何估算、预算、管理、监督和控制项目成本，形成成本管理计划。

02

估算成本

算大概

对完成项目活动所需的成本进行近似估算，产出各项活动的成本估算。

03

制定预算

定基准

汇总各项活动的估算成本，建立经批准的成本基准（含应急储备，BAC 由此而来）。

04

控制成本

盯偏差 · 管变更

监督成本绩效、管理成本基准变更——今天学的 EVM（挣值分析）就属于这个过程。

成本管理主线：先定规则 → 再估算 → 再定基准 → 最后控偏差

02今天学了什么

01基础变量
  • PV：计划价值
  • EV：挣值
  • AC：实际成本
  • BAC：完工预算
  • 四个核心变量是 EVM 的基础！
02偏差与绩效
  • CV = EV - AC（成本偏差）
  • SV = EV - PV（进度偏差）
  • CPI = EV / AC（成本绩效指数）
  • SPI = EV / PV（进度绩效指数）
03完工预测
  • EAC：完工估算
  • ETC：完工尚需估算
  • VAC：完工偏差
  • 不同场景选择合适的 EAC 公式！
04剩余绩效
  • TCPI：为实现目标，剩余工作所需的成本绩效指数
  • 判断目标能否守住的关键指标！

挣值曲线怎么画：PV / AC / EV 三条线

— PV 计划价值（S 曲线） - - AC 实际成本 - - EV 挣值
画法五步：
1. 横轴 = 时间，纵轴 = 累计成本；
2. 先画 PV：按计划安排画 S 曲线，终点 = BAC；
3. 在检查日期画一条竖线（检查点）；
4. 检查点上标 AC：实际花掉的钱；
5. 检查点上标 EV：完成工作的预算价值。
读图判断：
EV 在 AC 下方 → CV = EV − AC < 0，成本超支；
EV 在 PV 下方 → SV = EV − PV < 0，进度落后；
图中情形 = 又超支又落后（双输，最警惕）。
口诀：PV 定基准（S 形到 BAC），AC 看花费，EV 看完成；检查点上一竖线，线上比高低——EV 夹在中间最惨。

按当前效率往下画：完工预测线（EAC）怎么画

实线段 = 已发生的事实；虚线段 = 按当前效率的预测，只能从检查点往后画。
画法：
1. AC 从检查点继续向右上延伸，终点 = EAC（高于 BAC → 预计超支）；
2. EV 从检查点继续向右上延伸，终点一定落在 BAC 线上（干完活就挣满预算）；
3. 横轴要延长到预测完工日期，并标出比"计划完工"延后多少；
4. 两条预测线的落点差 = VAC（完工偏差）。
注意点：
① 历史段不能改：PV/AC/EV 已发生部分画实线，预测段一律虚线；
② 先判断偏差类型再选公式：典型（会持续）EAC = BAC ÷ CPI；非典型（例外）EAC = AC + (BAC − EV)；自下而上 EAC = AC + 新 ETC；同时受进度影响用 CPI×SPI；
③ 完工时 EV = BAC，AC = EAC，别把 EV 终点也画到 EAC；
④ EAC 在 BAC 之上 → VAC < 0 预计超支，反之为结余；
⑤ 别忘了配 TCPI：TCPI = (BAC − EV) ÷ (BAC − AC)（按 BAC 完成时），> 1 说明剩余工作必须比现在更省，目标难守住；
⑥ 单位口径一致，且延长期必须画在横轴上，否则会读错成"提前完工"。
