①知识地图

挣值管理（EVM）把「范围 · 进度 · 成本」三个维度整合到一个坐标系里：8 个指标描述现状 + 4 个指标预测未来。

4 个基础数据（先找齐再算）

缩写全称含义
PVPlanned Value计划价值 · 到某时点计划应完成工作的预算成本
EVEarned Value挣值 · 到某时点实际完成工作的预算成本（核心）
ACActual Cost实际成本 · 到某时点已完成工作的实际花费
BACBudget At Completion完工预算 · 整个项目的总预算

4 个绩效指标（描述"现状"）

  • CV = EV − AC：成本偏差，<0 超支
  • SV = EV − PV：进度偏差，<0 落后
  • CPI = EV / AC：成本绩效指数，<1 超支 / >1 节约
  • SPI = EV / PV：进度绩效指数，<1 落后 / >1 超前

4 个预测指标（回答"未来"）

  • ETC：完工尚需成本 Estimate To Complete
  • EAC：完工时总成本 Estimate At Completion = AC + ETC
  • VAC：完工偏差 = BAC − EAC
  • TCPI：剩余工作需达到的绩效指数（>1 较难达成）

②公式速查

建议截图保存到手机，刷题时随查随用。

绩效（现状） CV = EV − AC （<0 超支） SV = EV − PV （<0 落后） CPI = EV / AC （<1 超支，>1 节约） SPI = EV / PV （<1 落后，>1 超前） 预测（未来 · 关键看典型/非典型） 典型（按当前绩效继续）： ETC = (BAC − EV) / CPI EAC = BAC / CPI 非典型（剩余按预算效率）： ETC = BAC − EV EAC = AC + (BAC − EV) 通用： VAC = BAC − EAC TCPI = (BAC − EV) / (BAC − AC)

③计算思路 · 5 步法

  • 第 1 步 · 找齐 PV、EV、AC、BAC：题干常以"截至第 N 周末"或表格给出，按公式所需提取即可。
  • 第 2 步 · 算绩效指标：CV / SV / CPI / SPI，代入即可；EV 永远是"预算"，不要拿 AC 当 EV。
  • 第 3 步 · 写结论：CPI<1 且 SPI<1 = 成本超支且进度落后 → "项目需采取纠偏措施"。
  • 第 4 步 · 判断典型 / 非典型：题干关键词是分水岭（见下表）。
  • 第 5 步 · 套公式求预测值：问"还需多少"→ ETC；问"完工总花费"→ EAC；问"还差多少预算"→ VAC。

典型 vs 非典型 · 关键词对照

类型题干关键词公式选择
典型按当前趋势继续 / 不采取纠正措施 / 当前绩效代表未来 / 剩余工作也按当前效率ETC = (BAC − EV) / CPI
EAC = BAC / CPI
非典型采取纠正措施后 / 剩余工作按原预算效率 / 偏差不再延续ETC = BAC − EV
EAC = AC + (BAC − EV)
🧠 举例理解 · 非典型 EAC 为什么是 AC + (BAC − EV)
展开讲解
【基础数据】 总预算 BAC = 100 万；已完成 30% → EV = 30 万；实际花了 AC = 40 万（已超支 10 万）。
CPI = EV / AC = 30 / 40 = 0.75；剩余工作量的预算值 = BAC − EV = 70 万。

【铁律】 EAC = AC + ETC 永远成立，两种算法的区别只在 ETC 怎么算。

① 典型（默认 · 按当前绩效继续）
剩下 70 万的活，还按 0.75 的低效做 → 实际要花更多：
ETC = (BAC − EV) / CPI = 70 / 0.75 ≈ 93.3 万
EAC = AC + ETC = 40 + 93.3 = 133.3 万（继续亏）

② 非典型（剩余按预算效率 · 已止血）
剩下 70 万的活，恢复到 1:1 正常预算 → 花了多少算多少：
ETC = BAC − EV = 70 万（直接用预算值，不再除 CPI）
EAC = AC + (BAC − EV) = 40 + 70 = 110 万（亏损封顶在 10 万）

【三句话记住】
· 70 万是"剩下活儿值多少钱（预算口径）"，不是"还剩多少钱能花"。
· 非典型下 EAC ≠ BAC：已超支的钱收不回来，只能止损、不再扩大。
· 判断：题干说"剩余工作按原预算效率 / 已采取纠正措施"→ 非典型；没特别说明 → 默认典型。
🧠 举例理解 · TCPI = (BAC − EV) / (BAC − AC) 到底在算什么
展开讲解
【一句话】 从现在到完工，剩下的活必须"多高效"，才能把项目按预算干完。

【把公式掰开】
TCPI = (BAC − EV) / (BAC − AC)
分子 BAC − EV = 剩下活儿值多少钱（预算口径）
分母 BAC − AC = 口袋里还剩多少钱可以花
本质：用剩下的钱干完剩下的活，每一块钱要换出多少产出。

【接着 BAC=100 / EV=30 / AC=40 这组算】
TCPI = (100 − 30) / (100 − 40) = 70 / 60 ≈ 1.17
读法：剩 70 万的活、只剩 60 万可花 → 必须每 1 元做出 1.17 元产出，难度偏高。

【三种情形一眼判断】
· TCPI > 1（如 1.17）→ 已超支、预算紧，必须更高效，难达成。
· TCPI = 1 → 保持节奏即可按预算完工，正常。
· TCPI < 1（如 0.60）→ 之前节约、预算宽，轻松。

【与 CPI 的关系（过去 vs 未来）】
CPI = EV / AC → 衡量"已完成部分"的成本效率（已经发生）
TCPI = (BAC − EV) / (BAC − AC) → 衡量"剩余部分必须达到"的成本效率（尚未发生）
之前 CPI < 1（超支），TCPI 通常 > 1（后面要补回来）。

【速判】 题目问"剩余工作要达到怎样的成本绩效才能按预算完成"→ 直接套公式，一眼看 >1 / =1 / <1。

④规律与注意点

💡 EV 易错：EV = "已完成工作的预算价值"，与 AC（实际花费）口径不同。不要把 AC 当 EV 用。 💡 "截至某检查日"的题：只取该时点的 PV/EV/AC，不要套用整个项目的数据。 💡 成本与进度可一好一坏：CPI>1 同时 SPI<1 = 节约但落后，结论要分别写，不能笼统说"项目状态良好"。 💡 TCPI 越大越难达成：>1 意味着剩余工作要"超额效率"才能不超支；=1 表示刚好按预算完成；<1 表示宽松。 💡 VAC：正值=剩余预算能撑住，负值=必超支。 💡 答题四件套：① 列数据 ② 算指标 ③ 写结论 ④ 提建议（加强成本/进度控制、必要时调整资源或赶工）。

⑤例题演练

以下为根据历年考试规律改编的仿真题，覆盖典型 / 非典型两类，点击可展开答案。

例题 1（典型）：某项目 BAC = 100 万。第 5 周末统计得 PV = 50 万、EV = 45 万、AC = 60 万。假设项目按当前绩效继续，请判断当前状态，并求 EAC 与 VAC。
显示答案
CV = EV − AC = 45 − 60 = −15 万（超支）
SV = EV − PV = 45 − 50 = −5 万（落后）
CPI = EV / AC = 45 / 60 = 0.75（成本绩效差）
SPI = EV / PV = 45 / 50 = 0.9（进度落后）
典型 → EAC = BAC / CPI = 100 / 0.75 ≈ 133.33 万
VAC = BAC − EAC = 100 − 133.33 = −33.33 万
结论：项目成本超支、进度落后，需采取纠偏措施（如赶工、加强成本控制）。
例题 2（非典型）：某项目 BAC = 200 万，截至第 8 周末 PV=80 万、EV=70 万、AC=90 万。管理层决定采取纠正措施，剩余工作按原预算效率执行。求 ETC、EAC、TCPI。
显示答案
非典型（剩余按预算效率）→ ETC = BAC − EV = 200 − 70 = 130 万
EAC = AC + ETC = 90 + 130 = 220 万
VAC = BAC − EAC = 200 − 220 = −20 万（完工将超支 20 万）
TCPI = (BAC − EV) / (BAC − AC) = 130 / 110 ≈ 1.18
结论：剩余工作需达到 1.18 的效率才能按预算完成，难度较高。
