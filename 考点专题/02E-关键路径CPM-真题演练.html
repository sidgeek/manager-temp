真题演练 · 2021 下第 45-46 题（总浮动 + 工期）

题目：某项目包含 A~J 共 10 个活动，各活动历时与逻辑关系如下表。施工过程中，活动 B 延期 2 天。问：B 的自由活动时间与总活动时间分别为（45）天，工期是（46）天。
活动历时（天）前置活动活动历时（天）前置活动
A2—F4C、D
B2AG4E、F
C3AH3G
D4AI2G
E3BJ1H、I

（45）A. 0，1　　B. 1，2　　C. 2，2　　D. 1，1
（46）A. 17　　　B. 18　　　C. 19　　　D. 20

显示答案
正推法（ES / EF）：
活动ABCDEFGHIJ
ES02224610141417
EF245671014171618

逆推法（LS / LF）：
活动ABCDEFGHIJ
LS05327610141517
LF2766101014171718

关键路径：A → D → F → G → H → J，总工期 = 18 天。

浮动时间：
  • 自由浮动 FF(B) = ES(E) − EF(B) = 4 − 4 = 0 天
  • 总浮动 TF(B) = LF(B) − EF(B) = 7 − 4 = 3 天
  • B 已延期 2 天，剩余总浮动 = 3 − 2 = 1 天；自由浮动仍为 0 天。

⚡ 速算法（不用逆推全表）：枚举 6 条路径 → 关键路径 A-D-F-G-H-J = 18 天；经过 B 的最长路径 A-B-E-G-H-J = 15 天 → TF(B) = 18 − 15 = 3。详见计算篇 · 总浮动速算法。

结论：（45）选 A. 0，1；（46）选 B. 18。

真题演练 · 2021 上第 44-45 题（自由浮动 + 关键路径条数）

题目：某项目的单代号网络图（七格图）如下。活动 B 的自由浮动时间为（44）天，该项目的关键路径有（45）条。
七格网络图 · 上排 ES / 工期 / EF，下排 LS / TF / LF（空格 = 题目留空待推算）
标准七格图：上排 ES / 工期 / EF，中行活动名，下排 LS / TF / LF；空白格为题目留空、需自行推算。

（44）A. 0　　B. 1　　C. 2　　D. 3
（45）A. 4　　B. 3　　C. 2　　D. 1

显示答案
（44）活动 B 的自由浮动时间 —— 秒判 0，不需要任何工期
  • B 的紧后活动是 E，而 E 的唯一紧前活动就是 B（B → E 独占）。
  • 所以 E 的最早开始完全由 B 决定：ES(E) = EF(B)。
  • FF(B) = ES(E) − EF(B) = 0。

⚡ 通用秒判规则：若活动 X 存在某个紧后活动 Y，且 Y 的唯一紧前就是 X，则 X 一定"驱动"了 Y，必推出 FF(X) = 0。
这与 X 本身是否在关键路径上无关，也完全不需要知道工期。

（45）关键路径条数 —— 判定逻辑
  • 题图已标 D 的 TF = 0 → D 是关键活动。D 的紧前是 A、紧后是 F，故 A → D → F → G 必定是一条关键路径（F 也被 D 驱动成关键活动）。
  • 还剩两条候选，各只需比一次工期和：
    • A → C → F → G 是否也是关键路径？看 DU(C) 是否等于 DU(D)（两者都从 A 出发并汇入 F）。相等则 C 也关键，+1 条。
    • A → B → E → G 是否也是关键路径？看 DU(B) + DU(E) 是否等于 DU(D) + DU(F)。相等则 B、E 也关键，+1 条。
  • 因此：关键路径条数 = 1 +（C 关键 ? 1 : 0）+（B、E 关键 ? 1 : 0），取值只可能是 1 / 2 / 3。


完整七格参数表（推算后）：
活动ABCDEFG
ES02225711
工期2345642
EF2567111113
LS02325711
TF0010000
LF2577111113

正推要点：F 的 ES = max(EF_C, EF_D) = max(6, 7) = 7，EF = 7 + 4 = 11；G 的 ES = max(EF_E, EF_F) = max(11, 11) = 11。总工期 = 13 天。

（45）确定答案：关键路径 = 2 条
  • 枚举三条路径：A-B-E-G = 2+3+6+2 = 13；A-D-F-G = 2+5+4+2 = 13；A-C-F-G = 2+4+4+2 = 12。
  • 最长为 13，故关键路径共 2 条：A → B → E → G 与 A → D → F → G。
  • C 的 TF = 1（非关键），所以 A-C-F-G 这条不是关键路径。

结论：（44）选 A. 0；（45）选 C. 2。

❗ 易错提醒：不要看到"A、D、G 的 TF = 0"就以为只有 1 条关键路径。TF = 0 只说明该活动在某条关键路径上；关键路径的条数必须由各分支的工期对比决定。

真题演练 · 2020 下第 44-45 题（总浮动 + 自由浮动 + 最短工期）

题目：下图（单位：周）为某项目实施的单代号网络图，活动 E 的总浮动时间与自由浮动时间为（44），该项目的最短工期为（45）。
活动ABCDEFGH
历时（周）21587121282

依赖关系：A → B、C、D；B → H；C → E、G；D → F；E → H；F → G；G → H。
（44）A. 5，0　　B. 7，5　　C. 7，7　　D. 7，0
（45）A. 31　　　B. 30　　　C. 20　　　D. 19

显示答案
枚举路径法：起点 A → 终点 H 共 4 条路径。
路径长度（周）
A → B → H2 + 15 + 2 = 19
A → C → E → H2 + 8 + 12 + 2 = 24
A → C → G → H2 + 8 + 8 + 2 = 20
A → D → F → G → H2 + 7 + 12 + 8 + 2 = 31（关键路径）

（45）最短工期 = 31 周，选 A。

活动 E 的浮动时间：
  • 总浮动 TF(E) = 总工期 − 经过 E 的最长路径 = 31 − 24 = 7 周
  • 自由浮动 FF(E) = ES(H) − EF(E) = 29 − 22 = 7 周
  • 其中：EF(E) = ES(A) + DU(C) + DU(E) = 2 + 8 + 12 = 22；ES(H) = EF(G) = 2 + 7 + 12 + 8 = 29。

结论：（44）选 C. 7，7；（45）选 A. 31。

⚡ 关键发现：本题 E 的 TF = FF = 7，说明 E 虽然不在关键路径上，但它延迟 7 周内都不会影响 H 的最早开始，也不会影响总工期；超过 7 周才会影响。
