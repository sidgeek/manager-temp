①知识地图

立项时用 NPV、IRR、回收期、ROI 等指标判断一个项目"值不值得做"。

4 个常用财务指标

指标含义判断标准
NPVNet Present Value 净现值> 0 可行，多方案选最大
IRRInternal Rate of Return 内部收益率> 折现率（基准收益率）即可行
回收期Payback Period越短越好（一般 < 项目周期的一半）
ROIReturn On Investment 投资回报率= 收益 / 投资，越高越好

②公式速查

折现 PV = CF / (1 + r)ᵗ （r 是折现率，t 是年/期数，CF 是该期现金流） 净现值 NPV NPV = Σₜ CFₜ / (1 + r)ᵗ = −初始投资 + Σ（第 t 期净现金流折现到 t=0） 投资回收期（静态） = 累计净现金流首次 ≥ 0 的年份 若第 k 年累计 < 0，第 k+1 年转正，则： 回收期 = k + |第 k 年累计| / 第 k+1 年净现金流 ROI ROI = (收益 − 投资) / 投资 × 100%

③计算思路

题型 1：求 NPV

  • 把每年净现金流按 (1+r)ᵗ 折现到 t=0。
  • 初始投资记为负（在 t=0）。
  • 求和得 NPV。NPV > 0 → 项目可行。

题型 2：求投资回收期

  • 逐年累加（不折现），找首次 ≥ 0 的年份。
  • 内插法补足差额 → 精确回收期。

题型 3：多方案对比

  • 寿命相同 → 直接比 NPV，选大。
  • 寿命不同 → 用等额年金法或最小公倍数寿命法换算后再比。
  • 互斥项目比 NPV，独立项目看 NPV 是否 > 0。

④规律与注意点

💡 NPV > 0：项目实际收益率高于折现率，可行；多方案选 NPV 大的。 💡 折现率越大，NPV 越小：r ↑ → PV ↓ → NPV ↓，所以高折现率下"远期收益"的项目更容易被否决。 💡 初始投资放在 t=0：不折现，原始金额（负号）。 💡 回收期"动态 vs 静态"：题目默认静态（不折现），题干说"折现回收期"才折现。 💡 ROI ≠ 利润：ROI 是比率，需把分子分母同时折算（一致口径）后才能横向比较。 💡 NPV 与 IRR 矛盾时：互斥项目优先看 NPV；NPV 是绝对值，IRR 是比率。

⑤例题演练

例题 1：某项目初始投资 100 万，预计未来 3 年每年净收益 50 万，折现率 10%。问 NPV 与投资回收期？
显示答案
折现系数：(1.1)¹=1.1, (1.1)²=1.21, (1.1)³=1.331
PV₁ = 50/1.1 ≈ 45.45
PV₂ = 50/1.21 ≈ 41.32
PV₃ = 50/1.331 ≈ 37.57
NPV = −100 + 45.45 + 41.32 + 37.57 ≈ 24.34 万（可行）

静态回收期：第 1 年末累计 −50，第 2 年末累计 0 → 2 年
例题 2：某项目初始投资 200 万，第 1 年净收益 80 万，第 2 年净收益 100 万，第 3 年净收益 150 万。求静态投资回收期。
显示答案
第 1 年末累计 = 80 − 200 = −120
第 2 年末累计 = 100 − 120 = −20
第 3 年末累计 = 150 − 20 = 130（首次 ≥ 0）

回收期 = 2 + |−20| / 150 = 2 + 0.13 ≈ 2.13 年
