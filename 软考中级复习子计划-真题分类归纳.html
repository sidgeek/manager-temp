3.1 高频挣值分析 EVM 与完工预测

知识点
PV 计划价值 · EV 挣值（已完成工作的预算价值，核心）· AC 实际成本 · BAC 完工预算。成本状况看 CV/CPI，进度状况看 SV/SPI。
公式
CV = EV − AC （<0 成本超支） SV = EV − PV （<0 进度落后） CPI = EV / AC （<1 超支，>1 节约） SPI = EV / PV （<1 落后，>1 超前） ETC(典型) = (BAC − EV) / CPI ETC(非典型) = BAC − EV EAC = AC + ETC EAC(典型) = BAC / CPI EAC(非典型) = AC + (BAC − EV) VAC = BAC − EAC TCPI = (BAC − EV) / (BAC − AC)
常见问题与计算思路
  • 求 CV/SV/CPI/SPI：先找齐 PV、EV、AC → 代入；结果为负 / 小于 1 即不利。
  • 判断状态：CPI<1 且 SPI<1 = 成本超支且进度落后，需说明"采取措施"。
  • 预测 ETC/EAC：第一步先判断典型还是非典型再套公式。
  • 求"完工还需多少" → 问的是 ETC；求"完工总花费" → 问的是 EAC。
  • TCPI：越大越难达成，用于回答"剩余工作需达到多高效率"。
规律与注意点
💡 典型判定口诀：题干出现"按当前趋势继续 / 不采取纠正措施 / 当前绩效代表未来"→ 典型（用 CPI）；出现"采取纠正措施后按计划执行 / 剩余工作按预算效率"→ 非典型（用 BAC）。 💡 EV 易错：EV 是"已完成工作的预算值"，不要拿 AC 当 EV。 💡 题干"截至目前 / 检查点时"→ 用该时点数据，不要用全项目数据。 💡 成本与进度可同时恶化、也可一好一坏，答题要分开写结论。

3.2 高频关键路径 CPM / 网络图 / 浮动时间

知识点
活动、紧前关系（FS 完成-开始、SS、FF、SF）、提前量 lead / 滞后量 lag；六个时间参数：ES、EF、LS、LF、总浮动 TF、自由浮动 FF；关键路径 = 最长路径 = 总工期。
公式
EF = ES + 工期 LS = LF − 工期 总浮动 TF = LS − ES = LF − EF 自由浮动 FF = min(紧后活动的 ES) − 本活动 EF 总工期 = 关键路径长度（最长路径） 关键活动：TF = 0
常见问题与计算思路
  • 正推（左→右）：从起点算 ES、EF，多个紧前取最大值。
  • 逆推（右→左）：从终点算 LF、LS，多个紧后取最小值。
  • 算 TF，把 TF=0 的活动连起来即关键路径；最长路径验证总工期。
  • 问"延误 X 天是否影响工期"→ 看该活动 TF 是否小于 X。
  • 有 lead/lag 时，在对应的依赖关系上加减（lead 减、lag 加）。
规律与注意点
💡 关键路径可能不止一条，题目常埋"两条关键路径"的坑。 💡 ES 从 0 开始还是从 1 开始，以题目给的网络图约定为准。 💡 总浮动为 0 的不一定是关键活动（题目约定不同），以"最长路径"为准最稳。 💡 压缩工期只能压关键路径上的活动；非关键活动压缩不影响总工期。 💡 自由浮动只影响紧后活动最早开始，考点少但易考判断。

3.3 高频三点估算与概率（PERT）

知识点
用乐观值 O、最可能值 M、悲观值 P 估算工期/成本；区分三角分布与 β（PERT）分布。
公式
β 分布(PERT 默认)：Te = (O + 4M + P) / 6 三角分布： Te = (O + M + P) / 3 标准差： σ = (P − O) / 6 方差： σ² 概率区间：±1σ ≈ 68.26% ｜ ±2σ ≈ 95.46% ｜ ±3σ ≈ 99.73%
常见问题与计算思路
  • 先判断分布：给"乐观/最可能/悲观"三值、未特别说明 → 默认 PERT（4M）。
  • 求某工期完成的概率：先算 Te 与 σ → 换算成落在几个 σ 区间 → 查经验百分比。
  • 多活动总工期：期望相加；标准差用方差相加再开方（σ总 = √(σ₁²+σ₂²)）。
规律与注意点
💡 只有 β 分布才用 4M，"平均三点"是三角分布 (O+M+P)/3，别混。 💡 σ 只由 P、O 决定，M 不影响离散程度。 💡 概率题答案常给几个区间百分比选项，记住 68/95/99.7 三档即可。

3.4 高频进度压缩与资源优化

知识点
赶工（加资源/加班，增成本、范围不变、风险低）；快速跟进（并行搭接，增风险、可能返工）；资源平衡（影响关键路径、延长工期）；资源平滑（不影响关键路径与工期）。
公式
赶工成本斜率 = (赶工成本 − 正常成本) / (正常工期 − 赶工工期) 选择原则：在关键路径上，优先压缩"单位时间成本最低"的活动
常见问题与计算思路
  • 问"如何压缩到 X 天、最少增加多少成本"：只动关键路径 → 按成本斜率从小到大逐项压缩。
  • 压缩后关键路径可能转移，需重新计算。
  • 问"用哪种压缩方式"：保进度且不重排逻辑 → 赶工；时间紧、逻辑允许并行 → 快速跟进。
规律与注意点
💡 赶工"花钱换时间"，快速跟进"用风险换时间"，二者都不会减少范围。 💡 资源平衡 = 动关键路径 = 可能延长工期；资源平滑 = 不动关键路径 = 工期不变——这是最爱考的对比点。 💡 压缩到极限后可能产生新的关键路径，别忘了复算。

3.5 中频决策树与期望货币值 EMV

知识点
用于不确定性下的方案选择，是定量风险分析常用工具。
公式
EMV = Σ (每种结果的概率 × 该结果的货币值) 选择：收益型取 EMV 最大；成本型取 EMV 最小
常见问题与计算思路
  • 画出决策树：决策节点（□）→ 机会节点（○）→ 各分支标概率与金额。
  • 自右向左累加各机会节点的 EMV，比较方案。
  • 常与"是否投标/是否开发某模块"结合，注意扣除固定成本。
规律与注意点
💡 概率之和必须为 1，若给"成功 70%"，则失败按 30% 计。 💡 金额含正负（收益为正、风险损失为负），别漏负号。 💡 常与风险应对"转移/减轻"结合出小问。

3.6 中频成本构成、合同与财务计算

知识点
成本估算方法（类比/参数/自下而上/三点）、应急储备与管理储备、合同类型（总价/成本补偿/工料）、立项财务指标（NPV / 回收期 / ROI）。
公式
成本基准 = 成本估算 + 应急储备（不含管理储备） 总预算 = 成本基准 + 管理储备 沟通渠道 = n(n − 1) / 2 NPV：把各年现金流按折现率折现后求和，越大越好
常见问题与计算思路
  • 问"成本基准是多少"→ 把各工作包估算加应急储备，不要加管理储备。
  • 问"总预算"→ 成本基准 + 管理储备。
  • 合同判断题：谁承担更多风险 → 总价合同风险在卖方、成本补偿在买方、工料居中。
  • NPV/回收期：优先选 NPV 大、回收期短的方案。
规律与注意点
💡 管理储备不属于成本基准，动用需高层批准——高频判断题。 💡 估算精度：类比最粗、自下而上最准也最耗时、参数估算靠模型。 💡 合同类型题常与"风险归属"一起考，记住"总价→卖方、补偿→买方、工料→共担"。

找茬清单
